## Problem

A vision-language model can describe an image in fluent text, and fluent text can hide recognition mistakes. This project checks a DeepSeek vision-language model against human judgement on two tasks: object recognition and scene understanding.

## Approach

The comparison harness scores the model's outputs against human-annotated ground truth, then breaks the disagreements down in an error analysis. The work was done for ECEN 642, Digital Image Processing & Computer Vision, at Texas A&M.

## Results

The error analysis records where the model's object and scene descriptions diverge from the human annotations. No figures are given on this page.
